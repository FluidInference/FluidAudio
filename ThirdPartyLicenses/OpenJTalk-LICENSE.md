# OpenJTalk stack (Kokoro ANE Japanese text frontend)

The Japanese text-to-phoneme frontend links the VOICEVOX CORE C library
(`voicevox_core.xcframework`, release 0.17.0, downloaded as a SwiftPM binary
target from the upstream GitHub release) for its Open JTalk text analysis, and
downloads the Open JTalk UTF-8 NAIST-JDIC dictionary (v1.11) at first use.
Only the text-analysis entry points (`voicevox_open_jtalk_rc_*`) are used; no
VOICEVOX voice models are downloaded or used.
