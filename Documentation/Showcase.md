# Showcase

More apps and projects built with FluidAudio. See the [README showcase](../README.md#showcase) for the featured list, and make a PR if you want to add your app — please keep it in chronological order.

| App | GitHub | Description |
| --- | :---: | --- |
| **[mac-whisper-speedtest](https://github.com/anvanvan/mac-whisper-speedtest)** | ✓ | Comparison of different local ASR, including one of the first versions of FluidAudio's ASR models |
| **[Starling](https://github.com/Ryandonofrio3/Starling)** | ✓ | Open Source, fully local voice-to-text transcription with auto-paste at your cursor. |
| **[Voxeoflow](https://www.voxeoflow.app)** | — | Mac dictation app with real-time translation. Lightning-fast transcription in over 100 languages, instantly translated to your target language. |
| **[Speakmac](https://speakmac.app)** | — | Mac app that lets you type anywhere on your Mac using your voice. Fully local, private dictation built on FluidAudio. |
| **[SamScribe](https://github.com/Steven-Weng/SamScribe)** | ✓ | An open-source macOS app that captures and transcribes audio from your microphone and meeting applications (Zoom, Teams, Chrome) in real-time, with cross-session speaker recognition. |
| **[WhisKey](https://whiskey.asktobuild.app/)** | — | Privacy-first voice dictation keyboard for iOS and macOS. On-device transcription with 12+ languages, AI meeting summaries, and mindmap generation. Great for daily use and vibe-coding. Uses speaker diarization. |
| **[Ora](https://futurelab.studio/ora)** | — | Local voice assistant for macOS with speech recognition and text-to-speech. |
| **[Flowstay](https://flowstay.app)** | — | Easy text-to-speech, local post-processing and Claude Code integration for macOS. Free forever. |
| **[macos-speech-server](https://github.com/dokterbob/macos-speech-server)** | ✓ | Wyoming (Home Assistant) and OpenAI compatible STT/transcription and TTS/speech API server. |
| **[Audite](https://github.com/zachatrocity/audite)** | ✓ | macOS menu-bar app that records meetings and transcribes them locally into Markdown notes for Obsidian. Uses Parakeet ASR via FluidAudio on the Apple Neural Engine. |
| **[Volocal](https://github.com/fikrikarim/volocal)** | ✓ | Fully local voice AI on iOS. Uses streaming Parakeet EOU ASR and streaming PocketTTS. |
| **[Parleq](https://parleq.app/)** | — | Privacy-first macOS dictation — press a hotkey, speak, paste cleaned-up text. On-device Parakeet TDT v3 ASR with CTC vocabulary boosting (audio never leaves the Mac), provider-pluggable LLM cleanup (Gemini/Vertex, Bedrock, Azure), and reference windows that bring on-screen context into the cleanup. Open source. |
| **[Plainsay](https://github.com/conrader/plainsay)** | ✓ | Native, MIT-licensed macOS dictation with local Parakeet and Whisper, a 12 MB signed download, and reproducible benchmarks. |
| **[Meetly](https://getmeetly.ai/)** | — | iPhone, iPad, and Mac app for recording and transcribing conversations on device, with searchable transcripts, audio replay, and optional AI summaries. Uses FluidAudio for Parakeet ASR and speaker diarization. |
| **[Wisp](https://smw.ai/projects/wisp)** | — | FREE, ultrafast English dictation for Mac that puts cleaned-up text in your app in 200-300ms after you stop talking. 3-10× faster than Wispr Flow, Superwhisper, MacWhisper, or OpenAI's GPT Transcribe, and nothing leaves your Mac. Uses Parakeet Unified ASR. |
| **[inlaut](https://inlaut.de/en)** | [✓](https://github.com/tobymarks/inlaut) | Open-source (GPL-3.0) menu bar push-to-talk dictation for macOS in German and English, including both mixed in one sentence. Fully on-device, no account. Uses Parakeet Ultra ASR on the Neural Engine. |
| **[Shiyin](https://github.com/juinwei7/Shiyin)** | ✓ | Open-source (MIT) meeting notes app for macOS. Records mic + system audio with a live transcript, transcribes locally with whisper.cpp (Breeze ASR 25, good at Mandarin–English code-switching), and writes timestamped notes with Claude Code, Codex or an API. Uses FluidAudio offline speaker diarization. |
| **[Dictaty](https://dictaty.com/en)** | — | Native macOS menu bar dictation. Hold a shortcut, speak, and release; the text goes into most editable fields on your Mac. Transcribes on device with Parakeet TDT v3 in 25 languages, so your audio stays on the Mac. 7-day free trial, then a one-time purchase. |
| **[Helicon](https://helicon.pages.dev/?tag=fluidaudio)** | — | Free PDF and EPUB reader for iPad and iPhone. Read aloud (in the public beta) speaks the book in 7 on-device Kokoro voices and lights each sentence as it is read; tap a line to move the voice there. Uses FluidAudio Kokoro TTS (`KokoroAneManager`). |
| **[Tamka](https://www.piedol.top/tamka/)** | [✓](https://github.com/piedol/tamka) | Open-source (GPL-3.0) menu bar dictation for macOS 26, written in Rust. Press a shortcut, speak, press it again, and the text is typed at the cursor, with filler words removed and 112 spoken commands for punctuation. Uses FluidAudio's Parakeet TDT ASR (Parakeet Ultra by default) on the Neural Engine, and publishes a benchmark of 11 model configurations against Whisper large-v3-turbo. |
| **[Barkenson](https://ziz11.github.io/Barkenson-Meeting-recorder-for-Mac/)** | [✓](https://github.com/ziz11/Barkenson-Meeting-recorder-for-Mac) | Free macOS meeting recorder with separate microphone and system-audio tracks, local transcription, and speaker diarization. Uses FluidAudio for on-device speech recognition and diarization. |
| **[Character Agent](https://apps.apple.com/us/app/character-agent/id6747638829)** | — | Character chat and roleplay for iOS with hands-free voice conversation. Speaks with local Paradee and Kokoro voices, transcribes on device with Whisper, and clones voices on device. |
